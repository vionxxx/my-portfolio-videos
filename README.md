## Usage

Each HTML file contains a video player with the corresponding MP4 file. The videos are configured to:
- Autoplay on load
- Loop continuously
- Start muted (with unmute option)
- Display in fullscreen mode

## GitHub Pages

When this repository is hosted on GitHub Pages, you can access the videos directly through the browser at:
`https://vionxxx.github.io/my-portfolio-videos/[ProjectName]/[filename].html`
